# 14 — Seed Data & Alpha

Seed only fictional development/staging data.

Do not ship seed passwords/accounts to production.
Do not use seed/sample metrics as public traction proof.

Suggested private alpha:
- 10–20 real founders
- overlapping problem areas
- track Founder Help Rate
- median first useful response
- confirmed help rate
- helper participation
- repeat asks
- reciprocity
- qualitative friction

Reopen Figma only from real evidence.
