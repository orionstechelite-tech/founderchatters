# 00 — Scope & Freeze

## Product objective

FounderChatters is not a content social network. It is a founder support network optimized around current needs, relevant experience, useful conversations, consent-based introductions, and confirmed contribution.

## North-star metric

**Founder Help Rate** = percentage of genuine asks receiving at least one useful response within 24 hours.

Supporting metrics:
- median first useful response time
- confirmed-help rate
- repeat asks
- helper participation
- reciprocity
- retention

Do not optimize MVP for vanity engagement such as posts, likes, followers or raw DAU without useful-help context.

## Frozen product constraints

- Request types: ASK / FEEDBACK / INTRODUCTION / COLLABORATION
- Save is a lightweight bookmark, not collections
- Messaging is basic 1:1 and request-linked
- Reputation is topic-specific contribution history
- Introductions require consent
- Admin has no unrestricted private-DM browser
- No user-facing AI in MVP

## Design freeze boundaries

Product UI, Admin UI, Marketing Website and Responsive Completion are frozen as of 27 Sep 2026.

Reopen Figma only for:
- implementation evidence
- real usability findings
- legal/privacy review
- accessibility problems
- alpha-founder feedback
- unavoidable technical constraints that materially affect UX
